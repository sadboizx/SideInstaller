1

Setup

Install DNS Profile
  1. Tap Install DNS Profile above and tap Allow when Safari asks to download the configuration profile.
  2. Open Settings and tap Profile Downloaded (or go to Settings → General → VPN & Device Management), then tap Install.
  3. Apply the DNS: in Settings → General → VPN & Device Management, open DNS and make sure SideInstaller is selected. Keep it enabled until setup is complete.
2

Signing

Pick an app and tap Sign, then choose a certificate — signing is automatic.

How to install
  1. Open this page on your iPhone or iPad in Safari.
  2. Pick an app below and tap Sign.
  3. Choose a certificate from the list.
  4. Signing happens automatically: the app's IPA is signed with your certificate using zsign on GitHub Actions (zsign can't run on Cloudflare Workers, so the heavy work happens there), then the install manifest is built — you just wait and watch the progress.
  5. When the manifest is ready, the iOS installer opens by itself. Confirm the prompt and wait for the app on your Home Screen.
  6. Go to Settings → General → VPN & Device Management, tap the developer profile, and Trust it.
  7. Launch the app. If one certificate is revoked or won't open, try another.
3

Completion

You're all set.

That's it. Open SideInstaller from your Home Screen and use it to install SideStore (or SideStore + LiveContainer), straight from your device. No PC needed.

Once SideStore is installed, the DNS profile is no longer needed. Remove it in Settings → General → VPN & Device Management → SideInstaller → Remove Profile — or keep it and just stop using its DNS by switching DNS back to Automatic in the same menu.
